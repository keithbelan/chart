# Chart Pilot

**Chart Pilot** is an interactive data visualization advisory chatbot built with Streamlit and Groq[span_1](start_span)[span_1](end_span). It helps analysts, students, and business users turn a business question and dataset schema into practical chart recommendations, tool-specific build steps, and visual highlighting techniques so the key insight stands out to stakeholders[span_2](start_span)[span_2](end_span).

## What It Does

* **Checks Required Context First:** Prompts users for three core inputs—the business question, column names with their data types, and the target visualization tool—before generating a full recommendation[span_3](start_span)[span_3](end_span).
* **Recommends Chart Options:** Evaluates analytical intent against data types to suggest primary, secondary, and alternative chart choices, clearly calling out the best fit[span_4](start_span)[span_4](end_span).
* **Gives Tool-Specific Steps:** Tailors implementation guidance to the requested tool(s), such as Power BI, Tableau, Excel, or Python (Seaborn/Matplotlib)[span_5](start_span)[span_5](end_span).
* **Guides Visual Highlighting:** Explains how to draw attention to the answer in the data using smart sorting, accent colors, conditional formatting, and callouts[span_6](start_span)[span_6](end_span).
* **Adapts to Follow-Ups:** Pivots the execution and highlighting steps if you choose an alternative chart option, keeps conversations focused on data visualization, and reminds users to clean data and verify data types[span_7](start_span)[span_7](end_span).
